# **App Name**: Surat Social Bites

## Core Features:

- QR Code Scanning (Table Specific): Users scan a unique QR code at any table to access the web application, which immediately recognizes their location (e.g., "Welcome! You're at [Food Court Name]!").
- Guest Access: Allows users to immediately start browsing and ordering after scanning a QR code, creating a temporary anonymous session without mandatory login or registration.
- Vendor Login: Provides a secure login for food stall owners to access their dedicated portal
- Stall Discovery: Unified Homepage (Stall List): Displays a visually rich, endlessly scrollable feed of all participating food stalls in a grid layout after scanning any QR code.
- Stall Discovery: Search & Filter: A prominent search bar to find stalls or specific dishes, with filter options by cuisine type.
- Stall Discovery: Stall Cards: Each card shows the stall's banner image, name, logo, aggregate star rating, and descriptive tags (e.g., "Pizza," "Chinese," "Dessert").
- Menu Browsing: Detailed Stall Menu: Tapping a stall card transitions the user to its dedicated menu page, organised into logical sections (e.g., "Appetizers," "Main Course").
- Menu Browsing: Item Details: Each menu item is accompanied by a high-quality photograph, price, item-specific star rating, and a social proof metric (e.g., "100+ ordered").
- Unified Cart: Multi-Stall Cart: A single, persistent cart that can hold items from multiple different stalls simultaneously, transforming a solo-stall experience into a food court-wide festival.
- Ordering: Item Customization: Detailed item pages with options for variants (e.g., Jain, No Onion/Garlic), spice level, and a text box for special instructions, with real-time price updates.
- Checkout & Payment: Simplified Checkout: A streamlined, multi-step flow on a single page to review the multi-stall order, request contact information (for guests), and select payment.
- Checkout & Payment: Multiple Payment Methods: Supports popular payment methods including UPI (via dynamic QR code) and Cash on Delivery (COD), mirroring common Indian payment infrastructure.
- Order Tracking: Unified Order Tracking Page: Displays a single order ID at the top, with individual cards for each stall in the order. Provides granular real-time updates for each item from each individual stall (e.g., "Accepted," "Preparing," "On the Way," "Delivered").
- Engagement: "What's Trending" Feed (Hyper-Local Social Proof): A real-time feed on the homepage showing the most ordered items across the entire food court, creating buzz and FOMO (Fear Of Missing Out) effect.
- Order Management: Real-Time Order Dashboard: A live feed of incoming orders with audible alerts, along with separate columns for "New Orders," "Preparing," and "On the Way" for active orders.
- Order Management: Order Actions: Provides one-click buttons for vendors to Accept or Reject an order (with an option to provide a reason for rejection).
- Order Management: Status Updates: Simple controls for vendors to update an order's status through its workflow (e.g., from "Accepted" to "Preparing" to "Ready" or "On the Way" and finally "Delivered").
- Menu Management: Full Menu Control: Vendors can add, edit, or delete categories and menu items, including setting price, description, images, and defining customization options.
- Menu Management: Real-Time Availability Control: A simple toggle switch allows vendors to mark an item as "Sold Out" instantly, which is immediately reflected on the customer-facing menu, preventing frustration.
- Profile Management: Stall Profile Management: Vendors can update their stall name, banner image, and descriptive tags (e.g., "Pizza," "Chinese").
- Operations: QR Code Generation: Vendors can generate and download unique QR codes for each table number associated with their stall.

## Style Guidelines:

- Primary Action Colour: Vibrant Orange (#FF6B00). This creates excitement and draws attention to key actions (CTAs).
- Background Colour: Off-White (#F8F9FA). This keeps the interface clean and readable.
- Surface Colour (for cards and contrasting elements): White (#FFFFFF).
- Primary Text Colour: Dark Gray (#212529).
- Secondary Text Colour: Medium Gray (#6C757D).
- Accent/Link Colour: Bright Blue (#00A7E1). This is for call-to-actions.
- Display Font (Headings): Satoshi. This is described as a modernist geometric sans-serif that adds personality and style to headings, pairing excellently with Inter for a clear visual hierarchy.
- Primary Font (UI/Body Text): Inter. This is a highly versatile, open-source sans-serif font designed for screen readability, with a large x-height for clarity at small sizes.
- Animations should be subtle and provide feedback, making the interface feel alive and responsive.
- Shimmering skeleton loaders: Show placeholders while content loads instead of a blank screen.
- Button feedback: A slight scale or colour change on tap.
- Smooth page transitions: Slide-in/fade-out transitions.
- "Add to Cart" Animation: A quick, satisfying animation where the item appears to fly from the button to the cart icon, with the cart icon giving a slight "bounce".
- Successful Order Placement Animation: A burst of celebratory confetti animation with a bold message like "Awesome! Your order is in".
- Pull-to-Refresh Indicator:  playful animation like a chef's hat flipping or a fork and spoon spinning can be used as a custom loading indicator. This aligns with the brand's personality.
- Interactive Card Hover/Press: When a user presses and holds (on mobile) or hovers (on desktop) over a stall card, the card should subtly elevate, cast a soft, diffused shadow, and may scale up slightly. This visual cue clearly indicates interactivity.
- Voice & Tone: Energetic, Authentic, Witty, Simple. The language should be casual, direct, and avoid corporate jargon. It will use modern slang where appropriate (e.g., "This pizza is fire!") and witty microcopy to create a friendly and relatable personality.
- Icon Style: Minimalist Line Icons (e.g., Feather Icons, Tabler Icons). These are easily recognizable, do not clutter the interface, and contribute to a modern and sophisticated look while maintaining clarity.
- Image Style: High-Quality, Authentic Food Photography. Gen Z values authenticity and can easily spot inauthentic stock photos. The platform will rely on vibrant and realistic photos of the food provided by the vendors to create an appealing and trustworthy visual experience
